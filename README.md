## Project Description
Three-in-One Game is a Unity game project that combines three different mini-games into one application. Players can choose a game from the main menu and enjoy different gameplay experiences.

This project is developed using Unity 6 and C#.

## Games Included

### 1. Mad Driver 🚗
- Control a car using the keyboard.
- Drive along the road and avoid obstacles.
- Use the pause menu to resume, restart, or return to the main menu.

### 2. Fly Like a Bird ✈️
- Control an airplane.
- Fly through the environment.
- Use keyboard controls to move the airplane.

### 3. I'm a Sumo and a Ball 🔴
- Control a ball in an arena.
- Compete against enemy balls.
- Avoid falling off the platform.
- Win or lose based on the game conditions.

## Features
- Main Menu with three game options
- Keyboard controls
- Pause and Resume
- Restart Game
- Return to Main Menu
- Exit Game
- Win and Game Over screens

## Technologies Used

## How to Run
1. Clone or download this repository.
2. Open Unity Hub.
3. Click **Add Project**.
4. Select the Unity project folder.
5. Open the project using the appropriate Unity Editor version.
6. Open the `mainmenu` scene.
7. Click **Play** to start.

## Project Purpose
The purpose of this project is to practice Unity game development, C# programming, game physics, user interface design, and scene management.
